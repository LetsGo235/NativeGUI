# NativeGUI 1.0.0-rc.1 — first public release candidate

Minecraft **1.21.1** · **NeoForge** · **client-side**.

An independently developed compatibility mod for supported custom GUI resource-pack formats. Includes support for common OptiFine Custom GUI `.properties`, a subset of older OptiGUI `.ini`, and a subset of OptiGUI 3 `.json` rules. No Fabric, OptiGUI, or Sinytra Connector dependency.

**Verified in manual tests (user-reported):** common vanilla container GUIs, named/conditional chests, red/purple shulker rules, biome rules, multiple pack priorities, repeated F3+T reloads, villager trading interfaces, horse/mule/llama inventories, and multiplayer client-side operation on an external server. Additional OptiGUI-required/recommended packs rendered successfully.

**Not yet claimed:** full OptiGUI parity, advanced NBT matching, GUI animation support, every third-party custom renderer, or universal compatibility with every pack.

Install only the **JAR** in the client `mods` directory. Keep your chosen resource packs in `resourcepacks` and enable them in game. Do not install multiple NativeGUI versions.

Project status: **release candidate / pre-release**. Please report issues with exact resource pack and mod versions.

Not an official Minecraft mod. Not approved by or associated with Mojang or Microsoft. Independent of OptiGUI and OptiFine.
